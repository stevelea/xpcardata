            How this page is served
          

          

            This dashboard is served by the XPCarData Android app's embedded HTTP server, directly from the car over
            your phone hotspot, home LAN or Tailscale. There is no cloud service in the middle and the page works
            fully offline: all HTML, CSS, JavaScript and icons are bundled as Flutter assets.
